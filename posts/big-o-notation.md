## Big-O 표기법이란?

Big-O 표기법은 알고리즘의 **효율성**을 나타내는 수학적 표기법입니다. 입력 크기 `n`이 커질 때 알고리즘이 얼마나 느려지는지(시간 복잡도)나 얼마나 많은 메모리를 사용하는지(공간 복잡도)를 표현합니다.

> 중요한 것은 정확한 값이 아니라 **입력 크기에 따른 증가율**입니다.

## 주요 복잡도 정리

| 표기법 | 이름 | 예시 |
|--------|------|------|
| O(1) | 상수 시간 | 배열 인덱스 접근 |
| O(log n) | 로그 시간 | 이진 탐색 |
| O(n) | 선형 시간 | 선형 탐색 |
| O(n log n) | 선형 로그 | 병합 정렬 |
| O(n²) | 이차 시간 | 버블 정렬 |
| O(2ⁿ) | 지수 시간 | 피보나치 재귀 |

## 예시 코드

### O(1) - 상수 시간

```python
def get_first(arr):
    return arr[0]  # 배열 크기와 무관하게 항상 1번 연산
```

### O(n) - 선형 시간

```python
def find_max(arr):
    max_val = arr[0]
    for x in arr:        # n번 반복
        if x > max_val:
            max_val = x
    return max_val
```

### O(n²) - 이차 시간

```python
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):          # n번
        for j in range(n - i - 1):  # n번
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
```

## Big-O 계산 규칙

1. **상수 제거**: O(2n) → O(n)
2. **낮은 차수 제거**: O(n² + n) → O(n²)
3. **최악의 경우 기준**: 평균이 아닌 최악 케이스로 분석

## 정리

알고리즘을 선택할 때는 항상 복잡도를 먼저 분석하는 습관을 가져야 합니다. 특히 입력 크기가 클수록 복잡도의 차이가 극명하게 나타납니다.
