## 프로세스(Process)란?

프로세스는 **실행 중인 프로그램**입니다. 디스크에 저장된 프로그램이 메모리에 올라와 CPU가 실행하는 상태를 말합니다.

각 프로세스는 독립적인 메모리 공간을 가집니다:

```
+------------------+
|      Stack       |  ← 함수 호출, 지역 변수
+------------------+
|      Heap        |  ← 동적 할당 메모리
+------------------+
|   Data Segment   |  ← 전역 변수, static 변수
+------------------+
|   Code Segment   |  ← 실행 코드 (Read-only)
+------------------+
```

## 스레드(Thread)란?

스레드는 프로세스 내에서 실행되는 **작업 단위**입니다. 하나의 프로세스는 여러 스레드를 가질 수 있습니다.

스레드는 프로세스의 자원을 **공유**합니다:

- **공유**: Code, Data, Heap 영역
- **독립**: Stack, 레지스터, PC(Program Counter)

## 핵심 비교

| 항목 | 프로세스 | 스레드 |
|------|---------|--------|
| 메모리 | 독립 | 프로세스 내 공유 |
| 생성 비용 | 높음 | 낮음 |
| 통신 | IPC 필요 | 메모리 직접 공유 |
| 격리성 | 강함 | 약함 |
| 오류 영향 | 해당 프로세스만 | 전체 프로세스 영향 |

## 멀티프로세스 vs 멀티스레드

### 멀티프로세스

```
Process A  |  Process B  |  Process C
  독립 메모리      독립 메모리      독립 메모리
```

- 장점: 안정성 (하나가 죽어도 다른 것에 영향 없음)
- 단점: 생성 비용 크고, IPC 통신 복잡

### 멀티스레드

```
            Process
  Thread1 | Thread2 | Thread3
    공유 메모리 (Heap, Code, Data)
```

- 장점: 빠른 생성, 메모리 공유로 통신 용이
- 단점: 동기화 문제(Race Condition), 하나의 스레드 오류가 전체에 영향

## 면접 단골 질문

**Q. 스레드는 왜 스택을 공유하지 않나요?**

스택은 함수 호출 정보(반환 주소, 지역 변수)를 저장합니다. 각 스레드는 독립적인 실행 흐름을 가지므로 자신만의 스택이 필요합니다.

**Q. 컨텍스트 스위칭(Context Switching)이란?**

CPU가 현재 실행 중인 프로세스/스레드의 상태를 저장하고, 다른 것을 실행하기 위해 상태를 복원하는 과정입니다. 프로세스 간 스위칭이 스레드 간 스위칭보다 비용이 더 큽니다.
